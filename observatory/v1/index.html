Границы данных

Здесь показаны добровольные события работы, а не реальные вызовы G2/Repo. REPORTED_COMPLETED означает сообщение чата, но не сохранение полного ответа. Старые файлы, удалённые из архива, не восстанавливаются из индекса; поступившие позже новые события могут быть отдельной записью.

Полная переписка, автоматическое подключение вкладок, исходящие уведомления и атрибуция вызовов инструментов по Chat ID не входят в V1.
