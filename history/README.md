# Исторические материалы

Оригиналы сохранены без переписывания. Их утверждения о путях, состоянии миграции, отсутствии Docker/интернета, ручном key и планируемых правах могут быть устаревшими.

Текущая точка входа: [README](../README.md), [CURRENT_STATE](../docs/CURRENT_STATE.md). Не исполнять команды из истории без сверки с текущей конфигурацией.

- prot/: прежние планы и docs из Documents\prot.
- repo-mode/: прежний WORKSPACE.md.
- bridge/: прежний README Bridge.
- snapshot-transfer/: reference copy документов отдельного owning repo.
- migration-manifest.json: исходные пути и SHA-256 перенесённых/скопированных документов.

Относительные ссылки отражают прежнее дерево; приложения и launcher paths оставлены на HOST.
