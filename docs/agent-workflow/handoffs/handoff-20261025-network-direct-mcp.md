- Подготовка реального временного теста сохранена в двух **черновиках** выше. Inline read-only Linux JavaScript preflight прошёл; Windows PowerShell AST, запуск helper и точные ручные команды не проверены/не завершены. Helper намеренно блокирован `throw`; не выдавать его как готовый.
- Пользователь уже поручил проверить прямое подключение. Это временный override MCP entry в существующем Repo runtime; постоянное удаление Bridge и все меры C-04 не приняты.
- [Read-RepoNetworkPolicy.ps1](../tools/Read-RepoNetworkPolicy.ps1) уже подготовлен, но **не запускался пользователем**. Ручной host-boundary JSON уже получен и разобран в WF-019; не путать эти два collector.
- Junction отложены пользователем. Godot/ручной запуск результатов сейчас не ближайшая задача.

## Ближайшая единица работы

1. Прочитать C-05, проверить и закончить helper и независимый ручной возврат. Сверить только относящиеся live pins/identity; исходники-копии `runtime/` не объявлять установленной конфигурацией.
2. Выдать пользователю короткое объяснение direct и точные **ручные Windows-команды** с hash guard, Preview/TestDirect/Restore. Предупредить о временном разрыве общего Repo: другие чаты и MCP terminal sessions могут пострадать. Контейнер не останавливать.
3. После ручного «direct запущен» проверить реальный serving process ancestry, небольшой известный файл и read-only terminal operation; metadata `get_config` отдельно не считать доказательством переключения. UI наблюдает пользователь; учитывать cache, не нажимать Apply/Send/feedback.
4. Выполнить ручной возврат и проверить прежнюю цепочку. Записать actual-client результаты и пределы; только затем решать между direct PR-A-13 и защищённым Bridge PR-A-07.
5. Для сетевой политики получить результат отдельного network collector и выбрать конкретный применимый enforcement. Текущие probes не доказывают полной host/LAN изоляции; не считать proxy env или firewall одного слоя готовой границей.

В C-05 уже разобраны важные детали: pinned controller можно dot-source без запуска Menu; старый startup `probe.mjs` **меняет** marker/DC/Git settings, поэтому не годится как read-only preflight; Restore должен работать из отдельного локального окна без доступного MCP.

## Разрешения

Работать через Linux Fortis Repo; Windows-действия выполняет пользователь вручную. Windows/G2-инструменты не использовать. Исследования не разрешают менять ACL, mounts, сеть, действующие launcher/profile/runtime или перезапускать сервисы. Временный тест выполняется только пользователем по завершённой инструкции; новые ключи/регистрации/аккаунты не нужны. Постоянное применение и push отдельно. Локальные осмысленные Git-коммиты относящихся документов разрешены.

Защита Repo, запуск результата из основной/тестовой Windows-учётки и возможная будущая работа с junction — разные задачи. Не возвращаться к старому маршруту хендоффа: уточнение пользователя и `c21d48f` имеют приоритет.
