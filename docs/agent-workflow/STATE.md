Основной источник этой инициативы — текущие файлы в `tunnel/docs/agent-workflow`, их история — локальные Git-коммиты. Коммит документации не применяет runtime. Push в этой работе не выполнялся; это отдельное действие.

Решения и изменения требований сначала отражаются здесь и в REQUIREMENTS/JOURNAL согласно [протоколу](README.md). Не вести второй конкурирующий «текущий план» в новом датированном файле без связи с этой точкой входа.
