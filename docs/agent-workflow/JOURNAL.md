Это объясняет механизм без предположения об admin-правах или доступе к личному профилю владельца.

**F-R-01 — Risk; UPSTREAM; unresolved.** Semantic target: Windows/G2 shell → host metadata → ответ ChatGPT, N-WF-02. Возможное последствие: в чат попадают не относящиеся к проекту сведения хоста даже при закрытых личных файлах. Переданное наблюдение иллюстрирует механизм; не устанавливает автоматически несанкционированность именно прошлого сбора. User Review Priority HIGH; Intervention Priority NEXT до продолжения соответствующего Windows-маршрута/заявления о его приватности. Связанный PR-U-02: selected candidate, impact UPSTREAM; выбранный отказ от Windows DC ещё не реализован и Risk этим не закрыт. Next Gate: отдельный ручной план прекращения этого доступа и проверка эффекта при переходе к реализации. Нового согласования желания убрать Windows DC не требуется.
