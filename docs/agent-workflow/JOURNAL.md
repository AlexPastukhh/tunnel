Возможное последствие: в чат попадают не относящиеся к проекту сведения хоста даже при закрытых личных файлах. Переданное наблюдение иллюстрирует механизм; не устанавливает автоматически несанкционированность именно прошлого сбора. User Review Priority HIGH; Intervention Priority NEXT до продолжения соответствующего Windows-маршрута/заявления о его приватности.
