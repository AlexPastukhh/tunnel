Интерфейс — лёгкая оболочка над готовыми анализаторами, а не новый собственный анализатор.

## Решение последнего сообщения

Приоритет имеет единое окно с **двумя отдельными кнопками «Проверить» и «Обновить»**. Регистрация пар заранее, запуск анализа и показ его результатов в этом же окне; обновление — отдельное действие после нормальных результатов и подтверждения. Совмещённая кнопка «Проверить и обновить» пользователем прямо исключена. Нужна лёгкая оболочка над инструментами. PowerShell может использоваться для первоначальной установки, но отдельное ежедневное переключение в консоль не является выбранным UX.
